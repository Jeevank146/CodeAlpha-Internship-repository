# 📊 Unemployment Analysis in India

## CodeAlpha Data Science Internship – Task 2

## 📌 Project Overview

This project focuses on analyzing unemployment trends in India using data analysis and visualization techniques.

The dataset contains unemployment information for different regions of India, including unemployment rate, estimated employment, labour participation rate, date, and area type.

The analysis was performed using Python in Google Colab.

---

## 🎯 Objective

The main objectives of this project are:

- Analyze unemployment trends in India.
- Understand unemployment differences between Rural and Urban areas.
- Identify regions with high and low unemployment rates.
- Analyze the impact of the COVID-19 period on unemployment.
- Study monthly unemployment trends.
- Analyze relationships between employment-related variables.
- Present the findings using visualizations.

---

## 📂 Dataset

The dataset used for this project is the **Unemployment in India** dataset obtained from Kaggle.

### Dataset Columns

| Column | Description |
|---|---|
| Region | State or region of India |
| Date | Date of the observation |
| Frequency | Frequency of data collection |
| Estimated Unemployment Rate (%) | Estimated percentage of unemployed people |
| Estimated Employed | Estimated number of employed people |
| Estimated Labour Participation Rate (%) | Labour participation rate |
| Area | Rural or Urban |
