# 📊 Unemployment Analysis in India

## CodeAlpha Data Science Internship — Task 2

This project analyzes unemployment trends across different regions and areas of India using Python, Pandas, Matplotlib, and Seaborn.

The analysis focuses on identifying unemployment patterns, regional differences, Rural vs Urban unemployment, and the impact of the COVID-19 period.

---

## 🎯 Objective

The main objective of this project is to analyze unemployment data and identify important patterns and trends across India.

The project includes:

- Data loading and inspection
- Data cleaning and preprocessing
- Missing-value analysis
- Exploratory Data Analysis (EDA)
- Rural vs Urban comparison
- Monthly unemployment trend analysis
- Regional unemployment analysis
- COVID-19 impact analysis
- Correlation analysis
- Data visualization
- Key findings and conclusions

---

## 📂 Dataset

The dataset used in this project is the **Unemployment in India** dataset obtained from Kaggle.

The dataset contains unemployment-related information for different regions of India.

### Dataset Features

| Column | Description |
|---|---|
| `Region` | State/region of India |
| `Date` | Date of observation |
| `Frequency` | Measurement frequency |
| `Estimated Unemployment Rate (%)` | Estimated unemployment rate |
| `Estimated Employed` | Estimated number of employed people |
| `Estimated Labour Participation Rate (%)` | Estimated labour participation rate |
| `Area` | Rural or Urban |
