# 🚗 Car Price Prediction with Machine Learning

## CodeAlpha Data Science Internship – Task 3

This project focuses on predicting the selling price of used cars using machine learning regression techniques.

The project performs data preprocessing, exploratory data analysis, feature engineering, categorical encoding, regression model training, model evaluation, feature importance analysis, and price prediction for a new car.

---

## 📌 Project Objective

The main objective of this project is to develop a machine learning model that can predict the selling price of a used car based on its characteristics.

The project also aims to understand how different vehicle features influence car prices and demonstrate the real-world application of machine learning for price prediction.

---

## 📂 Dataset

The dataset contains information about used cars and their selling prices.

### Dataset Size

- **Total Records:** 301
- **Original Features:** 9
- **Missing Values:** 0

### Features

| Feature | Description |
|---|---|
| `Car_Name` | Name of the car |
| `Year` | Manufacturing year of the car |
| `Selling_Price` | Selling price of the car (Target Variable) |
| `Present_Price` | Current/original price of the car |
| `Driven_kms` | Total kilometers driven |
| `Fuel_Type` | Fuel type of the car |
| `Selling_type` | Type of seller |
| `Transmission` | Transmission type |
| `Owner` | Number of previous owners |
